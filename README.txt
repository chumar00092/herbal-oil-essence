HERBAL OIL ESSENCE WEBSITE
===========================

FILES
- index.html: website content
- style.css: design and responsive layout
- script.js: WhatsApp and email order setup

BEFORE PUBLISHING
1. Open script.js in a text editor.
2. Change BUSINESS_WHATSAPP to your WhatsApp number with country code, digits only.
   Pakistan example format: 923001234567
3. Change BUSINESS_EMAIL to the email address where you want to receive enquiries.
4. Edit index.html to replace sample product names and descriptions with your real products.
5. Prices currently say “Ask us”; add real prices if you want.
6. Test the website on your phone before sharing it.

FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository, for example: herbal-oil-essence.
3. Upload index.html, style.css, and script.js to the repository's main/root folder.
4. In the repository, open Settings → Pages.
5. Under build/deployment, choose “Deploy from a branch”; choose the main branch and /(root), then Save.
6. Wait for the deployment to finish. GitHub will show your website URL in the Pages section.
7. Your website can be public and searchable, but appearing in Google search is not instant or guaranteed. Add a custom domain later if you want.

ORDER BEHAVIOUR
- Product buttons open a WhatsApp chat with a prepared message.
- The website order enquiry form opens the visitor's email app (mailto). It is not a database-backed order system.
- For direct online checkout, payment processing, order storage, or an admin panel, an additional store/backend service is needed.

IMPORTANT
- The listed products are sample placeholders, not verified real products.
- Use accurate ingredients, sizes, prices, delivery terms, and claims.
- Free hosting terms and interface labels can change; check the hosting provider's current documentation.
